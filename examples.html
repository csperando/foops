Examples

Copy, paste, catch.

Working patterns for the browser and the server. Each one uses only the public API.

Monitorsbrowser

Watch a remote interview

One session per interview. Log every verdict change, then post the final report.

const session = monitor.createSession();
session.on("change", (report) => log(report.verdict));
await session.start();

// when the interview ends
const report = session.stop();
await fetch("/interview/123/foops", {
  method: "POST", body: JSON.stringify(report) });
Servernode

Re-score in your API route

Ignore the client's verdict. Recompute it and flag reports that were edited by hand.

import { rescore } from "foops/server";

const { verdict, mismatches, versionMatches } =
  rescore(req.body);
if (mismatches.length) flagForReview(req.body);
Monitorsbrowser

One-shot check

No session: start, take the first readings, stop. Or run a single check by id.

const report = await monitor.run();
const signal = await monitor.checks.isExtended();
Servershared

Custom scorer

Combine signals your own way. The same scorer runs in the browser and in rescore().

const scorer = (signals) => {
  const { isExtendedIntegrity } = signals;
  if (isExtendedIntegrity?.outcome === "tampered")
    return { verdict: "unknown", score: null };
  return monitor.defaultScorer(signals);
};
monitor.createSession({ scorer });

Integrationhtml

Drop-in script tag

No bundler. Pin the version and add the SRI hash from jsDelivr.

<script src="https://cdn.jsdelivr.net/npm/foops@0.1.0/dist/foops.min.js"
  crossorigin="anonymous"></script>
<script>
  foops.monitor.run().then((r) => console.log(r.verdict));
</script>
