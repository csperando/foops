Catch the second screen.

foops reads the browser's newest platform APIs to spot extra monitors, virtual webcams and phony microphones. It also checks whether those APIs were patched to lie. Every finding ships as a JSON report that your server re-scores.

Extra monitors

Extended desktops, screens joined mid-session, windows dragged off the primary display and refresh-rate jumps, checked by twelve independent signals.

foops.monitor

Virtual webcams

Software cameras posing as real hardware, used to feed in a recording, a stand-in or a generated face.

webcam detector

Phony microphones

Virtual audio devices and routed inputs posing as a real microphone, used to pipe in a voice that isn't the candidate's.

microphone detector
Checks the checkers

Patched the API? That's a signal too.

Most detectors ask the browser a question and trust the answer. foops also checks whether the answer was rigged. It looks for replaced getters, shadowed properties and a rewritten toString, and checks that independent readings agree with each other.

Built for the server

Never trust a browser's verdict. foops doesn't.

The person being checked controls the browser. So the browser only gathers evidence, and your server recomputes every outcome from the raw data. If someone edits a report by hand, it shows up as a mismatch.

  1. 01 · Watch

    Start a session when the interview starts

    const session = monitor
  .createSession();
await session.start();
  2. 02 · Report

    Send plain JSON: signals and a timeline

    const report = session.stop();
await fetch(url, {
  method: "POST",
  body: JSON.stringify(report) });
  3. 03 · Re-score

    Recompute everything server-side

    import { rescore }
  from "foops/server";
const { verdict, mismatches }
  = rescore(report);
